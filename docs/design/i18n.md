# Cadence — Idioma de la interfaz (i18n)

Estado: **v1 hecha** (español, inglés, japonés). El engine no participa: es
puramente interfaz.

## Idea en una línea

Los textos viven en ficheros `.arb` (`ui/lib/l10n/`), Flutter genera con
`gen-l10n` las clases de traducción, y el código pide cada texto por su clave:
`context.l10n.<clave>`. **Nunca** se escribe texto de interfaz en el código.

## Ficheros

| Fichero | Qué es |
|---|---|
| `ui/lib/l10n/app_es.arb` | **Plantilla** y fuente de verdad de las claves (idioma de referencia: español). |
| `ui/lib/l10n/app_en.arb`, `app_ja.arb` | Traducciones (solo pares `clave: valor`). |
| `ui/l10n.yaml` | Configuración de `gen-l10n` (carpeta, plantilla, salida, fichero de claves sin traducir). |
| `ui/lib/l10n/app_localizations*.dart` | **Generados**. No se editan a mano. |
| `ui/lib/l10n/l10n.dart` | `context.l10n.<clave>` y `L10n.current.<clave>`. |
| `ui/lib/l10n/locale_store.dart` | Lee/escribe el idioma en `~/Music/Cadence/ui_settings.json`. |
| `ui/pubspec.yaml` | `flutter_localizations`, `intl`, `generate: true`. |

## Uso en el código

```dart
// Dentro de un build() o un callback con BuildContext:
Text(context.l10n.timelineAddTrack)

// Con marcadores de posición (definidos en el @clave del .arb de plantilla):
context.l10n.projectVersion(kAppVersion)

// Código SIN contexto (p. ej. EngineService, CustomPainter):
return L10n.current.serviceRecordingInProgress;
```

`L10n.current` se actualiza en el `builder` de los dos `MaterialApp`
(ventana principal y sub-ventanas). Si aún no hay app montada (tests puros,
arranque) cae al español en vez de reventar.

## Idiomas y persistencia

- Idiomas: `es`, `en`, `ja` (`supportedUiLocales` en `locale_store.dart`).
- Si el idioma del sistema no es ninguno de esos tres, se usa **español** (es el
  primero de la lista; `MaterialApp.supportedLocales` respeta ese orden).
- Selector: **Preferencias → Idioma** (Seguir al sistema / Español / English / 日本語).
  El nombre de cada idioma se muestra siempre en su propio idioma.
- Se guarda en `~/Music/Cadence/ui_settings.json` como `{"locale": "ja"}`
  (sin la clave = seguir al sistema). Es un fichero **solo de interfaz**,
  independiente del `settings.json` de audio/MIDI del engine.
- Las **sub-ventanas** (mixer / piano roll / automation) son procesos aparte,
  así que cada una lee el idioma del fichero al arrancar (`LocaleStore.load()`
  en `main()`).

## Añadir o cambiar un texto

1. Añade la clave a `app_es.arb` (con su `@clave` y `placeholders` si lleva
   marcadores) y a `app_en.arb` y `app_ja.arb`.
2. Genera: `flutter gen-l10n` (o simplemente `flutter pub get` / `flutter build`).
3. Comprueba que no queda nada sin traducir: `ui/build/l10n_untranslated.txt`
   debe contener `{}`.
4. Usa la clave en el código (`context.l10n.<clave>`).

Nombres de clave por zona: `app*` (shell), `transport*`, `timeline*`,
`mixer*`, `pianoRoll*`, `automation*`, `channel*`, `export*`, `addTrack*`,
`plugin*`, `project*`, `soundLib*`, `service*` (mensajes del servicio),
`pref*` (preferencias), `alert*` (cuadros de alerta).

## Añadir un idioma

1. Copia `app_es.arb` a `app_<código>.arb` y traduce los valores.
2. Añade `Locale('<código>')` a `supportedUiLocales`
   (`ui/lib/l10n/locale_store.dart`) y un chip en `_languageChip`
   (`ui/lib/ui/preferences_dialog.dart`).
3. `flutter gen-l10n`.

## Errores y avisos (relacionado)

Los errores se muestran con **cuadros de alerta** (`ui/lib/ui/app_alert.dart`):
`showAppError(context, mensaje, {detail})`. Los mensajes que devuelve
`EngineService` ya vienen traducidos (usa `L10n.current` internamente); el texto
técnico que añade el engine C++ (`lastError`) se muestra tal cual, como detalle,
porque es diagnóstico y no se traduce.

## Qué NO se traduce (a propósito)

- Nombres de pista, de plugin, de parámetro y categorías del catálogo de sonidos:
  son **datos**, no interfaz.
- Valores musicales y símbolos: `1/4`, `1/8`, `IQ:`, `M`/`S`/`R`, `BPM`, `Hz`,
  `-inf`, `+ FX`, `WAV`, `MP3`, extensiones y rutas de fichero.

## Tests

- `ui/test/l10n_test.dart`: los tres idiomas resuelven, el cuadro de alerta se
  pinta y el idioma persiste (usa `LocaleStore.overrideFile` para no tocar el
  fichero real del usuario).
- Los tests de widget montan la app con
  `localizationsDelegates: AppLocalizations.localizationsDelegates`,
  `supportedLocales: ...` y `locale: const Locale('es')`, para que las
  expectativas de texto sigan siendo legibles en español.
